# F-EQ Pro 0.6.0

Windows x64 VST3, CLAP and standalone. Proprietary freeware by Fazıl Irak; source is not included.

- Fixes Undo/Redo after A/B comparison.
- Adds multi-band selection, relative group edits and Mixed values.
- Improves HP/LP nodes, analyser interpolation/tilt, display range and output layout.
- Musical/Surgical dynamic curves and independent Standard/High processing quality.
- Adaptive Linear Phase FIR prioritises narrow bass accuracy and reports real latency. Changing quality while playing is deferred until transport stops.

Local validation: 17 test groups passed, 128 quality measurements, 460 phase/character measurements, 1,058 CLAP checks and pluginval strictness 10. Real DAW acceptance, human blind listening and direct reference-product comparison remain separate. Extreme 192 kHz / 8-sample Spectral stress still exceeded callback deadlines. Very narrow bass Linear FIR can add seconds of latency; use Zero Latency for realtime playing.
